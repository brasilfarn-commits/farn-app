Restaurar Backup de Dados

Restaura no Firestore os cadastros (alunos, turmas, usuarios, projetos, TFMs e apontamentos) a partir de um arquivo de backup farn-backup-*.json.

Atencao: esta operacao sobrescreve os dados atuais no Firestore com o conteudo do arquivo selecionado. Use o backup mais recente e completo (ex.: farn-backup-2026-08-03T21-42-47.json, com 58 candidatos). Nao use os arquivos pequenos de 08-04.
